# Changelog 2.0.3

## 🦊 Native NeoForge Support (Minecraft 26.1.2)

- **Official NeoForge Implementation (`:neoforge`)**:
  - Full first-class support for **NeoForge 26.1.2+** on Java 25, turning DreamVoice into a true triple-platform solution alongside Paper and Fabric.
  - Dedicated mod entrypoint `DreamVoiceNeoForge` annotated with `@Mod("dreamvoice")`.
  - Simple Voice Chat integration via `@ForgeVoicechatPlugin` and `DreamVoiceVoicechatPlugin`.
  - Direct classloader isolation resolution: `:api` and `:common` are cleanly unified into the NeoForge source set with Jar-in-Jar bundling for external dependencies (Cloud, Vosk, JNA, Jackson, SnakeYAML).
- **Network Payload Protocol**:
  - Registered 43 packet codecs and 33 network receivers on `RegisterPayloadHandlersEvent`.
  - Fully handles both server-bound action packets and client-bound synchronization payloads.
- **PermissionAPI Integration**:
  - Automated scanning and registration of all `@Permission` nodes through NeoForge's `PermissionGatherEvent.Nodes` with OP / gamemaster permission levels.
- **Physical Cassette Item Handling**:
  - Right-click cassette playback handled seamlessly via NeoForge's `PlayerInteractEvent.RightClickItem`.

---

## ⌨️ Unified Command Syntax Across Platforms

- **Standardized Space-Separated Syntax (`/voice <module> <action>`)**:
  - Aligned command syntax across Paper, Fabric, and NeoForge to prevent naming inconsistencies.
  - Commands can now be uniformly invoked via the `/voice` root namespace:
    - `/voice radio <create|add|delete|remove|join|leave|list>`
    - `/voice broadcast <create|delete|remove|toggle|link|unlink|list>`
    - `/voice speaker <create|add|delete|remove|distance|mode|link|unlink|play|stop|list>`
    - `/voice record <start|stop|play|delete|cassette|export|extract|slice|radio|list>`
    - `/voice filter <list|apply|set|remove|clear>`
    - `/voice room <list|delete|remove>`
    - `/voice wall <info|toggle|mode|airdamping|debug>`
    - `/voice speech <status|keywords>`
    - `/voice wiretap <create|add|delete|remove|sub|listen|unsub|unlisten|cassette|list>`
    - `/voice projection <create|add|remove|delete|list>`
    - `/voice transmitter <enable|disable|list|clear|add|remove>`
    - `/voice debug <status|raycast>`
    - `/voice <status|save|load|reload>` (alongside `/dv` and `/dreamvoice`)
- **Backward-Compatible Direct Aliases**:
  - All direct command roots (`/radio`, `/broadcast`, `/speaker`, `/record`, `/filter`, `/room`, `/wall`, `/speech`, `/wiretap`, `/projection`, `/transmitter`, `/debug`) and glued aliases (`/voiceradio`, `/voicebroadcast`, `/voicespeaker`, etc.) remain fully functional.
