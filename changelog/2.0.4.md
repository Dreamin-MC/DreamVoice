# Changelog 2.0.4

## 📦 Build System & JitPack Support

- **JitPack Java 25 & API Isolation**:
  - Added dedicated `jitpack.yml` configuration targeting **OpenJDK 25** (`openjdk25`).
  - Configured `settings.gradle` to isolate the `:api` subproject during JitPack builds (`JITPACK` environment detection), avoiding unnecessary Fabric Loom and NeoForge ModDev initialization on JitPack containers.
  - Updated root `build.gradle` Java toolchain declaration (`JavaLanguageVersion.of(25)`) for native JitPack JDK auto-detection and scoped Maven repositories by group.
- **Release Pipeline Optimization**:
  - Resolved Gradle project configuration lock contention on multi-loader builds (`Paper`, `Fabric`, `NeoForge`).
