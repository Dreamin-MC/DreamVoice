# Changelog 1.0.7

## 💾 System Persistence & Storage
- **Automatic Lifecycle Persistence**: Automatic loading on server startup (`onServerStarted` once Simple Voice Chat API is ready) and automatic saving on server shutdown/plugin disable (`onDreamDisable`).
- **Independent JSON Storage**: Each voice module persists independently in `plugins/DreamVoice/data/`:
  - `speakers.json`: 3D fixed/mobile speakers, locations, ranges, modes (`GLOBAL`/`RESTRICTED`), linked players, and attached entities.
  - `wiretaps.json`: Spatial wiretaps, positions, listening ranges, attached entities, audio filters, and active listeners.
  - `projections.json`: Body anchors and vocal projections, audio emission/listening toggles, ranges, and filters.
  - `radios.json`: Radio frequency channels, Roger Beep settings, audio filters, and connected members.
  - `transmitters.json`: Transmitter modes and configured receivers with optional max distance ranges.
- **Java API Integration**:
  - New service `VoicePersistenceService` (`saveAll()`, `loadAll()`, `saveSpeakers()`, `loadSpeakers()`, `saveWiretaps()`, etc.).
  - Added direct `save()` and `load()` methods on all sub-services (`VoiceSpeakerService`, `VoiceWiretapService`, `VoiceProjectionService`, `VoiceRadioService`, `VoiceTransmitterService`).

---

## 🎮 Unified & Harmonized Commands
- **New Central Administration Command `/dreamvoice` (or `/dv`)**:
  - `/dv status`: Overview of active speakers, wiretaps, radio channels, projections, and VoiceWall mode.
  - `/dv save [all|speakers|wiretaps|projections|radios|transmitters]`: Save specific or all data modules to disk.
  - `/dv load [all|speakers|wiretaps|projections|radios|transmitters]`: Reload data modules from disk.
  - `/dv reload [all|config|data|<module>]`: Reload configuration (`config.json`), saved data (`data/*.json`), or everything.
- **Consistent Action Verbs Across All Modules**:
  - Support for both `add`/`create` and `remove`/`delete` across `/speaker`, `/wiretap`, `/radio`, and `/transmitter`.
- **New Detailed Inspection Commands**:
  - `/speaker info <name>`: Displays location, attached entity, range, mode, allowed speakers, and playback state.
  - `/radio info <channel>`: Displays channel audio filter, Roger Beep status, and active member list.
  - `/wiretap info <name>`: Displays location, attached entity, range, filter, recording status, and listener count.
  - `/projection info [player]`: Displays full anchor configuration, audio routing, and entity links.
- **Enhanced Utility Subcommands**:
  - `/radio kick <channel> <player>`: Expel a player from a radio frequency channel.
  - `/transmitter clear`: Clear all configured receivers from a transmitter.
- **Standardized Cassette Commands**:
  - Unified parameter ordering: ID/Name first, target player optional (e.g., `/record cassette <id> [player]`, `/wiretap cassette <name> [player]`).
