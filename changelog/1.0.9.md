# Changelog 1.0.9

## 🐛 Bug Fixes & Paper ClassLoader Isolation
- **Resolved Startup Crash (`NoClassDefFoundError: net/luckperms/api/LuckPerms`)**:
  - Fixed a critical initialization crash on Paper servers running LuckPerms caused by Paper's strict plugin classloader isolation (`PaperPluginClassLoader`).
  - Added `LuckPerms` as an optional dependency (`required: false, load: BEFORE`) in `paper-plugin.yml` so Paper properly authorizes class access if LuckPerms is installed on the server.
- **Eliminated ModelEngine Startup Warning**:
  - Resolved `[DreamVoice] Plugin ModelEngine is marked as hard dependency but not declared as such in plugin.yml or paper-plugin.yml!`.
  - Suppressed unneeded dependency checks during plugin initialization by opting out of DreamAPI's default gameplay and item registry services.

---

## 📦 Dependency & Distribution
- **DreamAPI Upgrade (`0.5.1` → `0.5.3`)**:
- **JitPack Availability**:
  - The `dreamvoice-api` is now available through [JitPack](https://jitpack.io/#Dreamin-MC/DreamVoice) for seamless Gradle and Maven dependency integration without requiring GitHub Packages authentication.
